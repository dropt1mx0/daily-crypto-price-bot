## Возможности

- Публикует оформленную карточку для **BTC, ETH, SOL, XRP, BNB, DOGE, TRX, ADA, LINK, AVAX и GRAM**.
- Отвечает на запросы по тикеру и названию монеты на русском и английском — в личных и групповых чатах.
- Конвертирует криптовалюту в USD, USDT, UAH и RUB, а также показывает эквивалент в BTC для поддерживаемых запросов.
- Публикует карточку по расписанию в часовом поясе Киева или с заданным интервалом.
- Поддерживает ручное обновление от администраторов Telegram.
- Получает данные CoinPaprika без API-ключа и кэширует ответы для запросов в чатах.
- Предоставляет `/healthz` для проверки состояния в Render и внешних мониторах.

## Запросы боту

| Запрос | Пример |
| --- | --- |
| Цена по тикеру или названию | `/price BTC`, `/price bitcoin`, `/price биткоин` |
| Конвертация суммы | `/convert 25 GRAM UAH` |
| Обычный текст | `грам биткоин` |
| Обновление карточки канала | `/update` — только для заданных администраторов |

Чтобы бот отвечал на обычные сообщения в группах, отключите Group Privacy Mode через [@BotFather](https://t.me/BotFather), затем удалите бота из группы и добавьте снова.

## Локальный запуск

Нужен Python версии 3.11 или новее.

```bash
git clone https://github.com/dropt1mx0/daily-crypto-price-bot.git
cd daily-crypto-price-bot
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\\Scripts\\activate
python -m pip install -r requirements.txt
cp .env.example .env            # Windows: copy .env.example .env
```

Добавьте Telegram-настройки в `.env`:

```dotenv
TELEGRAM_BOT_TOKEN=токен-от-BotFather
TELEGRAM_CHANNEL_ID=@имя_канала
TELEGRAM_ADMIN_USER_IDS=123456789
```

Добавьте бота в канал и выдайте ему право публиковать сообщения. Запустите:

```bash
python main.py
```

Отправьте боту `/start`. Команда `/update` от авторизованного пользователя немедленно опубликует карточку.

## Настройки

| Переменная | Обязательна | По умолчанию | Описание |
| --- | :---: | --- | --- |
| `TELEGRAM_BOT_TOKEN` | Да | — | Токен из [@BotFather](https://t.me/BotFather). |
| `TELEGRAM_CHANNEL_ID` | Да | — | Числовой ID канала или публичное имя вида `@channel`. |
| `TELEGRAM_ADMIN_USER_IDS` | Да | — | ID администраторов Telegram через запятую; им доступна команда `/update`. |
| `TIMEZONE` | Нет | `Europe/Kyiv` | Часовой пояс расписания и подписи на изображении. |
| `SCHEDULE_MODE` | Нет | `daily` | `daily` — по времени или `interval` — через интервал. |
| `PUBLISH_TIMES` | Нет | `23:10` | Время ежедневной публикации через запятую, например `09:00,18:30`. |
| `PUBLISH_INTERVAL_MINUTES` | Нет | — | Интервал в минутах при режиме `interval`. |
| `MAX_QUOTE_AGE_SECONDS` | Нет | `1800` | Максимальный возраст котировок для создания карточки. |

Полный список настроек находится в [`.env.example`](.env.example). Условия и доступность API CoinPaprika могут меняться — перед использованием за пределами личных задач проверьте [тарифы провайдера](https://coinpaprika.com/api/).

## Размещение на Render

Файл [`render.yaml`](render.yaml) описывает бесплатный Python-сервис. Подключите репозиторий в Render как Blueprint и добавьте три обязательные Telegram-переменные в настройках **Environment**. Не храните токены в Git или на скриншотах.

Бот получает обновления Telegram через long polling. HTTP-адрес `GET /healthz` позволяет Render проверять состояние процесса. Внешний монитор может периодически запрашивать этот адрес, чтобы уменьшить вероятность простоя на бесплатном плане. Render всё равно может перезапускать сервис, а локальная файловая система временная: SQLite-журнал публикаций не гарантированно переживает все перезапуски. Актуальные ограничения смотрите в [описании Render Free](https://render.com/docs/free).

## Предпросмотр карточки

После установки зависимостей выполните:

```bash
python image_generator.py
```

Команда создаёт `output/demo_preview.png` из синтетических котировок. Она не обращается к API, не запускает Telegram-бота и ничего не публикует.

## Структура проекта

| Файл | Назначение |
| --- | --- |
| `main.py` | Точка входа приложения. |
| `telegram_bot.py` | Команды Telegram, запросы из групп, публикация в канал и запуск health-сервера. |
| `api.py` | Запросы CoinPaprika, проверка котировок и кэш рыночных данных. |
| `chat_quotes.py` | Английские и русские названия, разбор запросов и конвертация. |
| `image_generator.py` | Рендер карточки и генерация синтетического предпросмотра. |
| `scheduler.py` | Расписание публикаций по времени или интервалу. |
| `publication_ledger.py` | Учёт опубликованных карточек в SQLite. |
| `config.py` | Список активов, пути, цвета и координаты изображения. |
| `assets/` | Шаблон баннера и круглые логотипы монет. |

## Данные и ограничения

- Карточка создаётся, только если для всех настроенных монет получены корректные и свежие котировки с изменением за 24 часа.
- Цены в карточке показываются в USD. Для конвертации используются котировки провайдера и вычисленные эквиваленты BTC/USDT.
- SQLite и логи — локальные runtime-данные, они исключены из репозитория.
- Условия CoinPaprika и разрешённые способы использования зависят от выбранного плана. Перед публичным распространением рыночных данных проверьте правила провайдера.
